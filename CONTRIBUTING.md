# Contributing to Blukit

We love your input! Blukit is built for the **Crowd**, not the **Web**. We are building a future where communication is physical, local, and anonymous. We want to make contributing as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features
- Becoming a maintainer

## Design Philosophy: The Spectral Field
Blukit follows a **Spectral Design System**. All UI components should:
- Use **Stealth Primary** (#00E5FF) and **Stealth Rose** (#FF4081) as the core energies.
- Favor atmospheric glows and pulsing animations over static borders.
- Replace standard system dialogs with **Vibe Ghosts** or **Blukit Alerts**.
- Maintain an anonymous-first, haptic-ready, and high-density UX.

## We Use [Github Flow](https://guides.github.com/introduction/flow/), So All Code Changes Happen Through Pull Requests

Pull requests are the best way to propose changes to the codebase. We actively welcome your pull requests:

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. **Verification**: Always verify changes against a physical device fleet (e.g., Pixel, OnePlus, Redmi, Moto) to ensure mesh stability.
5. **Hierarchy Compliance**: Ensure all new interaction layers (Ties) are anchored to a parent Air context.
6. Ensure the test suite passes.
7. Make sure your code lints.
8. Issue that pull request!

## Any contributions you make will be under the Apache 2.0 Software License

In short, when you submit code changes, your submissions are understood to be under the same [Apache 2.0 License](LICENSE) that covers the project. Feel free to contact the maintainers if that's a concern.

## Report bugs using Github's [issues](https://github.com/intellibitz/blukit/issues)

We use GitHub issues to track public bugs. Report a bug by [opening a new issue](https://github.com/intellibitz/blukit/issues/new); it's that easy!
