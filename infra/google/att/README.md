# AT&T Demo Suite (`web/google/att/`)

A client-server demonstration project showcasing cloud-backed mobile integration, built for the AT&T developer platform.

---

## Directory Overview

```
web/google/att/
├── client/
│   └── android/       # AT&T mobile client application for Android
└── server/
    └── appengine/     # Google App Engine cloud service backend
```

---

## Architecture Highlights

- **Client (`client/android`)**: Android application interfacing with carrier network services and cloud-hosted data feeds.
- **Server (`server/appengine`)**: Google App Engine backend providing scalable REST endpoints, session handling, and carrier integration logic.
