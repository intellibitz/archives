# Security Policy

## Supported Versions

We actively provide security updates for the following versions of **acc**:

| Version | Supported          |
| :---    | :---               |
| 1.x.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

We take the security of **acc** seriously. If you believe you have found a security vulnerability, please do **not** report it via a public issue.

Instead, please report it via [GitHub Security Advisories](https://github.com/intellibitz/acc/security/advisories/new). 

Alternatively, you can email the maintainers directly if a private security reporting feature is not available.

### What to include:
- A descriptive title for the vulnerability.
- A detailed description of the vulnerability and its impact.
- Steps to reproduce the issue (a Proof of Concept).
- Any possible mitigations you have identified.

### Response Timeline:
- You will receive an acknowledgment within 48 hours.
- We will provide a status update and a target fix date within 7 days.
- Once fixed, a security advisory will be published with credit to the reporter.

Thank you for helping keep the ACC community safe!
