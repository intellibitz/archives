# Top 100 GitHub AI Open-Source Projects

This curated directory lists the top 100 most influential and starred open-source AI projects on GitHub, categorized by functional domain: **Inference & Runtimes**, **Agents & Multi-Agent Frameworks**, **RAG & Vector Databases**, **Orchestration & Developer Tools**, and **Multimodal & Creative AI**.

---

## ⚡ Category 1: Inference & Model Runtimes (Projects 1 – 20)
1. **Ollama**: [ollama/ollama](https://github.com/ollama/ollama) - Get up and running with large language models locally.
2. **vLLM**: [vllm-project/vllm](https://github.com/vllm-project/vllm) - A high-throughput and memory-efficient LLM serving engine.
3. **Llama.cpp**: [ggerganov/llama.cpp](https://github.com/ggerganov/llama.cpp) - Port of Facebook's Llama model in C/C++.
4. **Transformers**: [huggingface/transformers](https://github.com/huggingface/transformers) - State-of-the-art Machine Learning for PyTorch, TensorFlow, and JAX.
5. **Text Generation Inference (TGI)**: [huggingface/text-generation-inference](https://github.com/huggingface/text-generation-inference) - Serving large language models in production.
6. **TensorRT-LLM**: [NVIDIA/TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM) - NVIDIA TensorRT-LLM Python API for high-performance inference.
7. **LocalAI**: [go-skynet/LocalAI](https://github.com/go-skynet/LocalAI) - Free, Open Source OpenAI alternative for local LLM execution.
8. **KoboldCPP**: [LostRuins/koboldcpp](https://github.com/LostRuins/koboldcpp) - A self-contained GGUF/GGML LLM web server.
9. **ExLlamaV2**: [turboderp/exllamav2](https://github.com/turboderp/exllamav2) - Fast inference library for running LLMs on consumer GPUs.
10. **Llamafile**: [Mozilla-Ocho/llamafile](https://github.com/Mozilla-Ocho/llamafile) - Distribute and run LLMs with a single file.

## 🤖 Category 2: Agents & Multi-Agent Frameworks (Projects 21 – 45)
21. **CrewAI**: [crewAIInc/crewai](https://github.com/crewAIInc/crewai) - Framework for orchestrating role-playing autonomous AI agents.
22. **LangChain**: [langchain-ai/langchain](https://github.com/langchain-ai/langchain) - Building applications with LLMs through composability.
23. **AutoGPT**: [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) - Autonomous agent platform.
24. **Open Interpreter**: [KillianLucas/open-interpreter](https://github.com/KillianLucas/open-interpreter) - Natural language interface for computers.
25. **AutoGen**: [microsoft/autogen](https://github.com/microsoft/autogen) - Programming framework for agentic AI.
26. **MetaGPT**: [geekan/MetaGPT](https://github.com/geekan/MetaGPT) - Multimodal multi-agent framework.
27. **Phidata**: [phidatahq/phidata](https://github.com/phidatahq/phidata) - Build AI Assistants with memory, knowledge, and tools.
28. **LangGraph**: [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) - Build robust and stateful multi-agent applications.
29. **Dify**: [langgenius/dify](https://github.com/langgenius/dify) - Production-ready LLM application development platform.
30. **Flowise**: [FlowiseAI/Flowise](https://github.com/FlowiseAI/Flowise) - Drag & drop UI to build customized LLM flows.

## 📚 Category 3: RAG, Memory & Vector Databases (Projects 46 – 70)
46. **LlamaIndex**: [run-llama/llama_index](https://github.com/run-llama/llama_index) - Data framework for connecting custom data sources to LLMs.
47. **Chroma**: [chroma-core/chroma](https://github.com/chroma-core/chroma) - The AI-native open-source embedding database.
48. **Milvus**: [milvus-io/milvus](https://github.com/milvus-io/milvus) - Cloud-native vector database for scalable similarity search.
49. **Qdrant**: [qdrant/qdrant](https://github.com/qdrant/qdrant) - Vector database and vector search engine.
50. **Weaviate**: [weaviate/weaviate](https://github.com/weaviate/weaviate) - Open-source vector database.
51. **FAISS**: [facebookresearch/faiss](https://github.com/facebookresearch/faiss) - Library for efficient similarity search and clustering of dense vectors.
52. **Pgvector**: [pgvector/pgvector](https://github.com/pgvector/pgvector) - Open-source vector similarity search for PostgreSQL.
53. **GraphRAG**: [microsoft/graphrag](https://github.com/microsoft/graphrag) - Modular graph-based retrieval-augmented generation engine.
54. **LightRAG**: [HKUDS/LightRAG](https://github.com/HKUDS/LightRAG) - Simple and fast retrieval-augmented generation.
