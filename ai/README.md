# AI Artifacts & Knowledge Base

This top-level directory houses AI-related artifacts, models, agent configurations, prompt templates, evaluation datasets, and LLM integration guides across the repository.

## Supported AI Providers & Models (`ai/`)
1. **[DeepSeek](./deepseek/)**: DeepSeek-V3, DeepSeek-R1, and related integration assets.
2. **[Qwen](./qwen/)**: Alibaba Qwen models and prompts.
3. **[OpenAI](./openai/)**: GPT-4o, o1, o3, and API integration scripts.
4. **[Claude](./claude/)**: Anthropic Claude models and prompts.
5. **[Xiaomi MiMo](./xiaomi-mimo/)**: Xiaomi MiMo model artifacts.
6. **[Zhipu GLM](./zhipu-glm/)**: Zhipu GLM-4 and related models.
7. **[Agnes AI](./agnes-ai/)**: Agnes AI models and prompts.
8. **[Google AI](./google-ai/)**: Gemini series models and SDKs.
9. **[Ministral / Mistral AI](./mistral/)**: Ministral, Mistral Large, and Codestral models.
10. **[Inclusion AI](./inclusion-ai/)**: Inclusion AI integration assets.
