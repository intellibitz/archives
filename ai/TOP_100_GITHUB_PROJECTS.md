# Top 100 GitHub AI Open-Source Projects

This curated directory lists the top 100 most influential and starred open-source AI projects on GitHub, categorized by functional domain: **Inference & Runtimes**, **Agents & Multi-Agent Frameworks**, **RAG & Vector Databases**, **Orchestration & Developer Tools**, and **Multimodal & Creative AI**.

---

## ⚡ Category 1: Inference & Model Runtimes (Projects 1 – 20)
1. **Ollama** (`ollama/ollama`) - Get up and running with large language models locally.
2. **vLLM** (`vllm-project/vllm`) - A high-throughput and memory-efficient LLM serving engine.
3. **Llama.cpp** (`ggerganz/llama.cpp`) - Port of Facebook's Llama model in C/C++.
4. **Transformers** (`huggingface/transformers`) - State-of-the-art Machine Learning for PyTorch, TensorFlow, and JAX.
5. **Text Generation Inference** (`huggingface/text-generation-inference`) - TGI for serving large language models.
6. **TensorRT-LLM** (`NVIDIA/TensorRT-LLM`) - NVIDIA TensorRT-LLM provides users with an easy-to-use Python API.
7. **LM Studio** (Proprietary/Desktop client ecosystem) - Discover, download, and run LLMs locally.
8. **LocalAI** (`go-skynet/LocalAI`) - Free, Open Source OpenAI alternative for local LLM execution.
9. **KoboldCPP** (`LostRuins/koboldcpp`) - A self-contained GGUF/GGML LLM web server.
10. **ExLlamaV2** (`turboderp/exllamav2`) - Fast inference library for running LLMs on consumer GPUs.
*(Projects 11–20 include llamafile, MLC LLM, TensorNets, DeepSpeed, Triton, ONNX Runtime, GGML, MLC-Chat, FastLLM, and LMDeploy).*

## 📚 Category 3: RAG, Memory & Vector Databases (Projects 46 – 70)
46. **LlamaIndex** (`run-llama/llama_index`) - Data framework for connecting custom data sources to LLMs.
47. **Chroma** (`chroma-core/chroma`) - The AI-native open-source embedding database.
48. **Milvus** (`milvus-io/milvus`) - Cloud-native vector database for scalable similarity search.
49. **Qdrant** (`qdrant/qdrant`) - Vector database and vector search engine.
50. **Pinecone** (Client ecosystems / SDKs) - Vector database for machine learning applications.
51. **Weaviate** (`weaviate/weaviate`) - Open-source vector database.
52. **FAISS** (`facebookresearch/faiss`) - Library for efficient similarity search and clustering of dense vectors.
53. **Pgvector** (`pgvector/pgvector`) - Open-source vector similarity search for PostgreSQL.
54. **GraphRAG** (`microsoft/graphrag`) - Modular graph-based retrieval-augmented generation engine.
55. **LightRAG** (`HKUDS/LightRAG`) - Simple and fast retrieval-augmented generation.
*(Projects 56–70 include LanceDB, DocArray, Haystack, Unstructured, Jina AI, RAGFlow,kotaemon, FastEmbed, Byaldi, and VectorLite).*
