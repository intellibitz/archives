BLUKIT - Offline Mesh Chat - Instant offline chat for stadiums, movie theaters & venues without internet.

Blukit is a decentralized, privacy-first offline messaging application for instant local peer-to-peer
(P2P) communication in high-density environments where cellular or Wi-Fi connectivity is
unavailable or unreliable — stadiums, movie theaters, concert venues, transit hubs,
crowded malls, and large events.

POWERS
1. Shout: Broadcast chat - all users in the mesh become part of the default group.
2. Whisper: one on one peer is user discretionary, optional.
3. User can shout in the Square, the Lobby, without any peers connected. 
4. User can Whisper to any connected user, selected, one on one.
5. Lobby Square is the landing screen - all users chat here, the mesh is the context. 
6. Messages are decentralized, users see every messages by all users in lobby square. 
7. Blukit is social communication tool, not a private secret tool. Design must ensure this power.
8. 
COMMANDMENTS
1. Must work purely on Bluetooth only. The only permission user must grant for Blukit.
2. Location - optional, no errors if location is denied.
3. Wifi - optional, no errors if location is denied.
4. I18N - For everyone, in any part of world. No technical expertise required, for regular users.
5. Privacy - Anonymous only - the user must not be tracked or reported by any means.
6. Safety - regular users be protected from spam, no spam will be tolerated.
7. Security - No secrets, passwords, username to be asked or given.
