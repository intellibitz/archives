BLUKIT - Offline Mesh Chat - Instant offline chat for stadiums, movie theaters & venues without internet.

Blukit is a decentralized, privacy-first offline messaging application for instant local peer-to-peer
(P2P) communication in high-density environments where cellular or Wi-Fi connectivity is
unavailable or unreliable — stadiums, movie theaters, concert venues, transit hubs,
crowded malls, and large events.

COMMANDMENTS
1. Must work purely on Bluetooth only. The only permission user must grant for Blukit.
2. Location - optional, no errors if location is denied.
3. Wifi - optional, no errors if location is denied.
4. I18N - For everyone, in any part of world. No technical expertise required, for regular users.
5. Privacy - Anonymous only - the user must not be tracked or reported by any means.
6. Safety - regular users be protected from spam, no spam will be tolerated.
7. Security - No secrets, passwords, username to be asked or given.
8.
POWERS
1. Watch: Broadcast chat stream - all users in the mesh become part of the default group. Can watch others shout when bluetooth enabled.
2. Whisper: User can Whisper to any connected user, selected, one on one peer is user discretionary, optional.
3. Shout: User can shout in the Square, the Lobby, without any peers connected. 
4. Lobby Square is the landing screen - all users chat here, the mesh is the context. 
5. Messages are decentralized, users see messages by all users in lobby square. 
6. Blukit is social communication tool, not a private secret tool. Design must ensure this power.
7. All powers comply fully with Blukit Commandments.
8. 
FLOWS
1. Blukit is a smart AI powered broadcast mesh chat - the user will be taken through the ux flows smartly.
2. The user lands in the lobby square. The user will have a default name "blukit" and default avatar "blukit logo".
3. The user can start his shout. The message is sent. Now Blukit shows the enable access for bluetooth, and says "hear others shout".
4. The user can whisper, one on one with others. Same smart flows.
5. The user can change his name and avatar, anytime. Voluntary and optional.
6. The user is able to shout, whisper from the moment he is on Blukit, the full powers activate as and when required.
7. All flows comply fully with Blukit Powers and Commandments.
