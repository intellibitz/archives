# Blukit

Blukit is an Android project designed to follow Google's development standards.

## Getting Started

### Prerequisites

- A Java Development Kit (JDK) 17 or newer installed on your system.
- Everything else (Android SDK, Gradle, Build Tools) is automatically handled by the Gradle Wrapper.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/intellibitz/blukit.git
   ```
2. Navigate to the project directory:
   ```bash
   cd blukit
   ```
3. Build the project using the Gradle Wrapper (this will download all necessary tools):
   ```bash
   ./gradlew assembleDebug
   ```

## Building the Project

To build the project, run:
```bash
./gradlew assembleDebug
```

## Running Tests

To run unit tests:
```bash
./gradlew test
```
